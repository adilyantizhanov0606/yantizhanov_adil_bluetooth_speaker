# Bluetooth Speaker Promotional Page
This repository contains the source code for a promotional website dedicated to the DR Sound Bluetooth Speaker. The project is built using HTML, CSS, SCSS, and JavaScript, featuring a custom-designed layout, interactive elements, product highlights, and responsive styling. The website is designed to showcase the speaker's features, design, and functionality while providing an engaging user experience across different screen sizes.
## Installation
No installation needed, just drag the html files into your preferred browser
